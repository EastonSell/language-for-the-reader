# Saved-evidence quickcheck

Delegated implementation choice: add a standard-library CLI, rather than asking users to run six commands or changing historical verifiers. It runs existing saved-evidence checks and synthetic regression tests only; no model training, download, evaluator, semantic rerating or gate reopening. Alternatives were documentation alone (less useful failure diagnosis) and changing aggregate defaults (would mix NumPy rebuild tests with saved-only verification).

`python -B tooling/check_saved_evidence.py [--json] [--timeout SECONDS]` works from any cwd, reports every stage, exits nonzero on any failure, and never treats a zero-exit incomplete cue analysis as success. Default stage timeout 120 seconds; accepted range is positive and at most 86400 seconds to avoid platform polling overflow. POSIX timeout stops the subprocess group; Windows only stops the direct child and has no guaranteed descendant/wall-clock bound (untested platform). JSON contains per-stage command, cwd, exit code, captured output, status and error. Human output includes full failed-stage output. Checks cover answerability, capacity, cue preparation/analysis/regressions, and finite-profile regressions. Successful verification does not mean the capacity gate passed or human comprehension improved. Frozen files remain unchanged. Trust is the checked-out code; this is not a security sandbox or new whole-tree authenticity claim.
