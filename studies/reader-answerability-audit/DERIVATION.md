## Public seal and scope

FILES.txt lists every public file, including PUBLIC_MANIFEST.json and PUBLIC_SEAL.json. The sealed release excludes all Python cache directories and bytecode; the verifier rejects cache artifacts instead of hiding arbitrary unlisted files in them. PUBLIC_MANIFEST.json supplies byte counts and SHA-256 hashes for every payload file and names the two self-authentication exclusions. PUBLIC_SEAL.json binds the manifest hash; neither can hash itself recursively. Independently retain the reported manifest hash if you need an external integrity anchor.

Public reproduction verifies file, source, case, quote, receipt-derivative and arithmetic consistency. It does not establish original runtime identity, verify unavailable child tool traces or backend transport bytes, prove no hidden access, or turn AI semantic review into human ground truth. The result remains a narrow exploratory check of a hypothetical shortcut, not population/general-model accuracy or causal question restoration.
