# Public metadata derivative

This package was assembled after collection. It is not a new pre-data freeze, preregistration or new experiment. ORIGINAL_FREEZE.json retains the exact original admitted freeze. DERIVATION.json records original and public SHA-256 hashes.

All stimuli, keys, scientific prompts, analysis code, tests and raw response bytes are unchanged. Three pre-data documentation files replace internal role/runtime wording with public study terminology. The public FREEZE.json binds that derivative and explicitly discloses its post-data status.

Only context_id values differ in results/receipts.json: actual private identities become context-01 through context-12. All times, prompt/raw hashes, requested configuration and unknown telemetry fields remain identical. Distinct pseudonyms do not independently prove distinct execution contexts; the independent reviewer inspected original identities privately. Original receipts and the identity mapping are preserved in the private evidence backup.

The unchanged analyzer was rerun on this derivative. Only freeze_sha256 differs from the byte-preserved results/original-analysis.json; scientific outcomes and denominators are identical. REVIEW.json is a public summary of independent pre-data and postrun review with hashes of the original review receipts, not an original execution record. Local paths, collection-management messages and internal coordination labels are omitted.

The package manifest binds public bytes. Neither hashes nor private review attestations provide backend-authenticated identity, original transport bytes, hard isolation or independent timestamp proof.
